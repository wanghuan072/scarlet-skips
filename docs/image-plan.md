# Scarlet Skips image plan

Live pages use official Steam media and captured base-game states. Generated editorial illustrations may remain in the asset archive, but they are not used by page content or metadata.

| Asset | Verified use | Important limitation |
| --- | --- | --- |
| `steam-header.jpg` | Official logo/key art | Promotional art, not gameplay evidence |
| `screenshot-1.jpg` | Baseline jumping and beginner context | Does not prove a numeric jump-height value |
| `screenshot-2.jpg` | Fire-rope state and visible multiplier | Does not prove the fire formula or Extinguish targeting |
| `screenshot-3.jpg` | Upgrade choice screen; Luck, Add Rope and Reinforce card names | Shows one random draw, not tier order |
| `screenshot-4.jpg` | Standard active-rope state | A still cannot establish rope speed |
| `screenshot-5.jpg` | Rocket Shoes / Rocket Fuel visual state | Does not prove fuel duration or refill behavior |
| `screenshot-6.jpg` | Broken-rope state | Does not establish exact durability |
| `screenshot-7.jpg` | Miss and recovery context | Does not establish the failure rule by itself |
| `achievement-off-to-a-great-start.jpg` | Official Steam achievement icon | Only use for the achievement guide |

Rules:

- Keep screenshots uncropped enough that the relevant game state remains readable.
- Captions must say what the frame proves and what it cannot prove.
- Do not reuse third-party mod thumbnails or author files. The Mods page links to original listings.
- Meaningful images use descriptive alt text. Decorative backgrounds carry no factual claim.
- Do not turn a screenshot into evidence for numeric speed, height, durability, probability or score formulas.
